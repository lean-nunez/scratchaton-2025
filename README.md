# 🧠 Scratchaton 2025 – Proyecto en Scratch

## 📚 Competencia organizada por OIA
**Scratchaton 2025** es una competencia educativa organizada por la **OIA (OLIMPIADAS INFORMATICAS ARGENTINAS)** con el objetivo de fomentar el pensamiento lógico, la creatividad y la resolución de problemas mediante la programación en **Scratch**.

Este año es **mi tercera vez participando**, demostrando compromiso, experiencia y mejora constante en el diseño de proyectos interactivos.

---

## ⚙️ Características del Proyecto
- 🎮 **Proyecto interactivo** desarrollado en Scratch.
- 🎨 Uso de **sprites, escenarios y efectos propios**.
- 🔁 Lógica de programación utilizando **bloques y eventos**.
- 💡 Mensaje educativo y creativo enfocado en el desafío propuesto por la competencia.

---

## 💡 Tecnologías y Herramientas Utilizadas
| Tipo | Herramienta / Recurso |
|------|-----------------------|
| Plataforma | Scratch |
| Animación | Sprites personalizados / Biblioteca Scratch |
| Lógica | Eventos, sensores, variables y bloques personalizados |
| Control de versión | GitHub (para documentación y respaldo) |

---

## 🧠 Objetivos del Proyecto
- Aplicar **pensamiento computacional** en un entorno visual.
- Desarrollar un proyecto **creativo, funcional y narrativo**.
- Promover el **aprendizaje autodidacta** y la **práctica constante**.
- Representar a mi institución en la **Scratchaton 2025** con dedicación y responsabilidad.

---

## 🎮 Cómo Ejecutar los juegos
1. Descargar el archivo `.sb3` de este repositorio.
2. Entrar a la página oficial de **Scratch**: https://scratch.mit.edu/
3. Hacer clic en **Crear**.
4. Luego en **Archivo → Cargar desde tu computadora**.
5. Seleccionar el archivo del proyecto.

Listo, el proyecto estará cargado y listo para usar o modificar.
